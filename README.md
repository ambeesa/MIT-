 Minorities In Tech Website

A responsive and interactive website for Minorities In Tech (MIT), showcasing the organization's mission, board members, and programs.

 Features
- Dynamic Navigation – Smooth scrolling and an animated navbar.  
- Homepage – Engaging intro with typewriter animation.  
- About Us – Overview of MIT's purpose and values.  
- Our Mission – Highlights key initiatives.  
- Our Board – Displays board members with images and roles.  
- Programs – Sections for general and affiliate programs.  
- Animations & Effects – CSS and JavaScript-based interactive elements.  
- Mobile-Friendly – Fully responsive layout.  

 Tech Stack
- HTML, CSS – Structure & styling.  
- JavaScript – Animations and interactivity.  
- Typed.js – Typewriter effect for key phrases.  
- Boxicons – Icons for social links.  

 Setup
1. Clone the repo:  
   ```
   git clone https://github.com/your-repo.git
   ```
2. Open `index.html` in a browser.
